# ProjectCard

A clickable tile for one app or project in the work grid.

- Whole card is one `<a>` to the case study. `surface-raised`, 1px `line` border, `radius-md`.
- 4:3 screenshot frame (`surface-sunken` while empty, labelled `[APP SCREENSHOT]`).
- `h3` title, one-line summary in `ink-muted`, up to 4 chips.
- Grid: 3 columns desktop, 2 tablet, 1 phone, `space-4` gap.
- The consumer provides: screenshot, title, summary, stack.
