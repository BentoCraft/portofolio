# ExperienceRow

One role in the experience timeline: dates left, details right.

- Two columns (200px / fluid) on desktop; dates stack above on phone.
- Dates in mono `label`, `ink-muted`. Role in `h3`, company in `accent`.
- 2–4 bullets in `body` / `ink-muted`, each starting with a verb.
- Rows separated by a `line` hairline on top; no cards.
