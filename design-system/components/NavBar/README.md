# NavBar

The site header: wordmark left, anchor links right, one accent CTA.

- Wordmark "Agus." in `display` 20px; the full stop is `accent` — the only logo.
- Links `ink-muted`, current section `ink`. CTA uses the primary Button look.
- `surface-raised` with a bottom `line` hairline; sticky on desktop.
- Phone: links collapse to a menu button (44px target, `aria-label="Menu"`).
