# Chip

A non-interactive tag naming a skill or technology.

- **Filled** (`accent-soft`, `ink` text): primary skills — Flutter, Dart, state management.
- **Outline** (1px `line`, `ink-muted` text): secondary tools.
- Mono `chip` style, `radius-pill`, 6×12px padding, `space-2` gaps, wrap freely.
- Render as an `<ul>` of `<li>`; chips are not buttons.
