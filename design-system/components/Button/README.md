# Button

The call to action: one primary per view, ghost for everything secondary.

- **Primary:** `accent` fill, `accent-ink` text, `radius-sm`, min-height 44px.
- **Ghost:** transparent, 1px `line-strong` border, `ink` text; border turns `ink` on hover.
- Optional trailing arrow icon (stroke 1.5) for navigation actions.
- Use `<a>` for navigation, `<button>` for actions. Focus: 2px `focus` ring, 2px offset.
- The consumer provides the label (verb first: "View my work", "Download CV").
